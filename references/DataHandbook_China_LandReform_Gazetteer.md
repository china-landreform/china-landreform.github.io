# 中国土地改革县志数据集 · 内部使用手册（Users' Guide ）

> A Handbook to the China Land-Reform County-Gazetteer Dataset
>
> 面向使用本数据集的研究者。本手册介绍数据的来源、结构、两阶段清洗流程与已知局限，帮助你在几分钟内判断数据是否适合你的研究，并正确地使用它。
>
> 版本对应：宽/长面板 `landreform_panel_wide/long.dta`（FDC 高级清洗链产出）。最后更新：2026-08。

---

## 0. 一分钟速览

- **是什么**：从 **30 个省级单位** 的县志（地方志）中系统摘录的 **土地改革（土改）前后** 农村土地占有、人口、户数、以及没收/分配数据。
- **规模**：**3,109 行**（其中县级 2,779 行，地级市/州汇总行 330 行），宽表约 1,777 个变量。
- **时间结构**：每个指标区分 **土改前（`pre`）** 与 **土改后（`post`）** 两个截面；没收/分配（`con`/`dis`）为改革过程量，无前后之分。
- **单位**：数据源单位极不统一（亩/公顷/垧/顷、斤/石/斗、万人/人、百分数 0–100 与小数 0–1 混录）。清洗后统一为 **亩、公斤、人、户、0–1 占比**。
- **质量透明度**：每个核心数值都带一对伴生列——`*_raw`（原始记录值，永不改动）与 `*_src`（来源旗标，记录该值是原始录入还是被填充/修正）。经统计，**97.9% 的核心数值为原始录入**，2.0% 为算法填充，仅约 0.1% 被覆写。
- **最重要的两条提醒**：(1) 占比一律使用 `*_u`（统一为 0–1）后缀变量，不要用原始 `*pct`；(2) merge 时用 `panel_uid`，**不要用 `code`**（地级市与下辖县共用同一 code）。

## 1. 数据来源与覆盖

**来源。** 数据摘自 30 省的县级地方志（县志）。县志多编纂于 1980–2000 年代，回溯记载本县土改时期（约 1949–1953 年）的土地占有与改革情况。原始摘录以每省一个 Excel 文件的形式录入。

**覆盖。**

| 维度 | 值 |
|---|---|
| 省级单位 | 30 |
| 面板总行数 | 3,109 |
| — 县级行（`admin_level=="县"`） | 2,779 |
| — 地级市/州汇总行（`admin_level=="市"`） | 330 |
| 时间截面 | 土改前 `pre`、土改后 `post` |

> **注意（覆盖 ≠ 完整）**：3,109 行是"有记录"的行，不代表每行都有完整数据。许多县志只报告县级总量或聚合口径，未细分到五个阶级（见 §6 覆盖率）。使用前请按你的分析需求筛选。

## 2. 数据处理总览：两个阶段

数据从原始县志 Excel 到分析级面板，经过**两个阶段**的处理。理解这两阶段的分工，是理解本数据集的关键。

```
                       原始县志 Excel（30 省，人工录入）
                                 │
          ┌──────────────────────┴──────────────────────┐
          │  阶段 A · 初步清洗（Python）                    │
          │  结构整理 → 列名统一 → 合并去重                 │
          └──────────────────────┬──────────────────────┘
                                 │  单表：3,109 行
          ┌──────────────────────┴──────────────────────┐
          │  阶段 B · 深度清洗（Stata）                     │
          │  DC 主链（单位/占比统一 + 交叉验证）             │
          │            ↓                                  │
          │  FDC 高级链（分类学 + 溯源 + 填充 + 协调 + 裁决） │
          └──────────────────────┬──────────────────────┘
                                 │
                 landreform_panel_wide / long（交付面板）
```

- **阶段 A（初步清洗，Python）** 解决的是**结构与一致性**问题：把 30 份格式各异的 Excel 变成一张干净、对齐、无重复的大表。它不改动任何数值的含义。
- **阶段 B（深度清洗，Stata）** 解决的是**测量与可比性**问题：统一单位、识别与标记异常、按缺失结构谨慎填充、构建可跨县比较的阶级分类层，并保留完整的数据溯源。

以下按**几个大方面**分别介绍，而非逐脚本罗列。

---

## 3. 阶段 A · 初步清洗（Python）——把 30 份 Excel 变成一张干净的表

### 3.1 结构整理（转置）
原始 Excel 是"每列一个县、每行一个指标"的宽格式。清洗第一步是**转置**为分析通用的"每行一个县"格式。

### 3.2 列名统一
各省录入者对同一指标的中文列名写法不一（全半角混用、措辞差异、同义不同名）。管线以**福建省的列名为唯一标准**，通过四层处理对齐所有省份：
- **全角化**：括号、冒号、百分号等半角字符统一转全角；
- **规则替换**：一批文本规则消除措辞差异（如「没收→没征收」「全县（市）→全县」）；
- **精确映射**：对无法用规则覆盖的列名逐一映射到标准名；
- **英文名兜底**：中文仍无法匹配时，借用录入表中的英文变量名跨省对齐。

### 3.3 合并与去重
- 30 份对齐后的省表按行**合并**成一张大表；
- 删除地理标识（省/市/县）全空的无效行；
- 以「省 + 市 + 县」三键**去重**，重复组内**保留缺失值最少的一行**。

### 3.4 阶段 A 产出
- `FinalData/all_merged_no_duplicates_final.xlsx` —— 合并去重后的单表，作为阶段 B（Stata）的输入；
- `FinalData/varname_mapping_corrected.dta` —— 中文/英文变量名对照表，是 Stata 阶段变量命名与标注的基础。

## 4. 阶段 B · 深度清洗（Stata）

阶段 B 由两条链组成：**DC 主链**（原始核心清洗与验证，产出 `codebook_data.dta`）和 **FDC 高级链**（在其上构建溯源、填充、协调与裁决层，产出交付面板）。下面按主题而非脚本编号介绍。

### 4.A 单位统一 —— 让不同来源的数字可比

源数据的单位是最大的一致性障碍。清洗把所有量纲统一到标准单位：

| 量纲 | 源数据中的形态 | 统一为 | 处理要点 |
|---|---|---|---|
| **土地面积** | 亩、市亩、习惯亩、公顷、公亩、顷、垧、万亩… | **亩**（`*_land_mu` / `*_area_mu`） | 按每县标注的原始单位查换算系数 |
| **粮食产量口径的"公斤"** | 少数县把土地按常年产量（公斤）记录 | **亩** | 反推系数 150 公斤/亩（西南稻作区单一系数） |
| **没收/分配的粮食** | 斤、石、斗、担/挑、吨 | **公斤**（`con_grain_kg` / `dis_grain_kg`） | 斤=0.5、石=75、斗=7.5、担=50、吨=1000 |
| **人口** | 个别县以"万人"录入 | **人** | 个案 ×10000 修正 |
| **占比（比例）** | 字符串"30%"、小数"0.3"、整数"30"混录 | **0–1 小数**（`*_u` 后缀） | 逐县判定格式后统一 |

> **占比统一的判定逻辑**：同一县的五个阶级占比中，若 ≥3 个值大于 1，则判为 0–100 百分数格式，整体 ÷100；否则视为 0–1 小数。结果写入 `*_u` 后缀变量（如 `pre_landlord_landpct_u`）。**分析请一律使用 `*_u` 变量。**

### 4.B 数据检查与交叉验证 —— 发现录入错误，但不擅自更改

清洗采用 **"检测标记（flag-only），不静默改值"** 的原则。多类自动检查交叉核对内部一致性，把可疑之处标记出来供人工判断，而非猜测性地修改：

- **量级检查**：某阶级的土地/人口是否超过了县级总量（物理上不可能）；县人均耕地是否异常偏高；分区加总与县总的偏差是否过大。
- **占比反推**：用 Σ(各阶级占比) 反推并与录入值对照，抓出占比格式混录的漏网县。
- **人均反推**：用 人口 × 人均 与 土地总量 对照，抓出量纲/小数点错位的县。
- **交叉验证**：各阶级之和是否吻合县级总量（分别在亩制、公斤制下核对）。

这些检查的阈值是**证据化**的——由全样本分布的 99 分位数取整确定，而非拍脑袋：

| 检查项 | 阈值（土改前 / 土改后） |
|---|---|
| 人均耕地上限 | 40 亩 / 20 亩 |
| 分区加总偏差 | 35% / 25% |

### 4.C 量纲陷阱检测 —— 占比的 0–100 vs 0–1 混录

这是本数据集**最需要注意**的一类问题，单列一节。占比类原始变量（`*pct` 族）中，大量县把"30%"记为 `30` 而非 `0.30`。清洗对所有原始占比变量做检测：值 > 1.5 即判为量纲混录嫌疑，打上 `dimtrap_flag` 并标记为待复核。

- 系统**只标记、不自动 ÷100**——因为无法排除极少数真实 >100% 的记录含义（如超额分配）。
- 极端实例：`pre_landlord_landpct` 的最大值达 69.3。
- **对使用者的意义**：永远用 `*_u`（已统一为 0–1）版本做分析，原始 `*pct` 仅供追溯。

### 4.D 缺失值处理 —— 谨慎、可追溯的填充

许多县志只报告部分信息（如只有县总、或只有占比）。清洗按一套**填充阶梯**在**只填缺失、绝不改动已录值**的前提下补全，且**每一次填充都打上来源旗标**，使用者可随时识别并剔除：

| 填充方式 | 逻辑 | 来源码 |
|---|---|---|
| 总量锚定 | 县级总量 ← Σ各分区 | `_src=11` |
| 末类反推 | 已知总量且仅缺一类时反算该类 | `_src=11` |
| 份额法 | 阶级绝对量 = 县总 × 统一占比 | `_src=12` |
| 人均法 | 阶级土地 = 人均 × 人口（或户均 × 户） | `_src=13` |
| 跨期互填 | 仅县总耕地面积，`pre`↔`post` 互补 | `_src=15` |
| 衍生量回填 | 人均 = 土地/人口、户均 = 土地/户 | `_src=11` |

> **关键约束**：跨期填充**只用于县级总耕地面积**，绝不跨期借用阶级占比——因为土改本身改变了阶级结构。若你的分析对填充敏感，可用 `drop if *_src==15`（或其它码）排除相应值。

### 4.E 阶级分类与协调层 —— 让不同县的阶级口径可比

不同县志的阶级划分粗细不一（有的分五类，有的只报"地富/贫雇"两组，有的用聚合口径）。清洗构建了两个**协调层（harmonized layers）**，把异质的原始口径映射到统一的可比结构：

- **h5（五类层，前缀 `h5_`）**：地主 `landlord`、富农 `richpea`、中农 `middle`、贫农 `poor`、雇农 `tenant`，加残差 `other`。
- **h3（三组层，前缀 `h3_`）**：地富 `lordrich`、中农 `middle`、贫雇 `poortenant`，加残差 `other`。h3 的口径更宽、覆盖更广，**推荐优先使用**。

关键归并依据 1950 年政务院《关于划分农村阶级成份的决定》：**半地主式富农 `halflord` → 并入富农组**；**上/下中农 `highmid`/`lowmid` → 并入中农组**。协调层通过一套选择矩阵避免原子类与聚合类的重复计数。

### 4.F 数据溯源 —— 每个数字的"户口本"

这是本数据集在同类历史数据中较为少见的特性：**每个核心数值都可追溯**。每个在范变量 `V` 都配一对伴生列：

- `V_raw` —— 原始记录值的快照（原缺失则为 `.`），**永不改动**；
- `V_src` —— 来源旗标（见下表）。不变式：`V_src==0 ⟺ V==V_raw`。

**来源码表（`fdc_src_lbl`）：**

| 码 | 含义 | 说明 |
|---:|---|---|
| 0 | original | 直接录入原始值，未改动 |
| 2 | hierarchy_overwrite | 聚合类与成员冲突时的层级覆写 |
| 3 | unit_corrected | 单位/量纲个案修正 |
| 9 | pending_review | 待人工裁决（异常或矛盾） |
| 11 | fill_absolute | 总量锚定 / 末类反推 / 衍生量回填 |
| 12 | fill_share | 份额法填充 |
| 13 | fill_percap | 人均法填充 |
| 15 | fill_cross_period | 跨期互填县总耕地 |
| 21 / 22 / 23 | manual_set / confirm / void | 人工裁决改值 / 确认 / 作废置缺 |

### 4.G 人工裁决闭环 —— 让专家判断进入数据

自动检查标记出的疑难格（`_src=9`），由研究者结合县志原文人工裁决。裁决通过一张标准表格（`adjudication_input.csv`：`panel_uid, varname, action, new_value, …`）回填进数据：`set`（改值→`_src=21`）、`confirm`（确认清旗→`_src=22`）、`void`（作废置缺→`_src=23`）。原值始终保留在 `*_raw`；任何 `panel_uid`/变量名匹配失败会**中止流程**，防止裁决被静默丢弃。

## 5. 交付数据的结构

### 5.1 两种形态：宽表与长表

| | 宽表 `landreform_panel_wide.dta` | 长表 `landreform_panel_long.dta` |
|---|---|---|
| 规模 | 3,109 行 × ~1,777 变量 | ~751,600 行 × 12 列 |
| 一行 = | 一个县 | 一个（县 × 期 × 层 × 阶级 × 维度）单元 |
| 行键 | `panel_uid` | `panel_uid + period + level + class + dim` |
| 适合 | 回归、跨变量分析、与外部县级数据 merge | 分面可视化、跨阶级分组统计、tidyverse 风格分析 |

两者均另附 `.xlsx`/`.csv` 副本（过大时退化为 CSV）。

### 5.2 变量命名规律

宽表变量名的通式：

```
[层前缀_]{period}_{class}_{dim}[_raw | _src]
```

| 槽位 | 取值 |
|---|---|
| 层前缀 | 无=原子层；`h5_`=五类层；`h3_`=三组层；`con_`/`dis_`=没收/分配族 |
| period | `pre`（土改前） / `post`（土改后） |
| class | 阶级或组名（见 §5.3） |
| dim | `land_mu`（亩）/ `popu`（人口）/ `hh`（户）/ `landpct`·`popupct`·`hhpct`（占比，原始）/ 同名 `_u`（统一 0–1）/ `percap`（人均土地）/ `perhh`（户均土地） |
| 后缀 | `_raw`（原值快照）/ `_src`（来源旗标）/ `_u`（统一占比） |

**解码示例：**
- `pre_landlord_land_mu` = 土改前 · 地主 · 土地面积（亩）
- `post_poor_popupct_u` = 土改后 · 贫农 · 人口占比（统一 0–1）
- `h3_post_poortenant_percap` = 三组层 · 土改后 · 贫雇农 · 人均土地
- `con_landlord_area` = 从地主没收的土地面积

### 5.3 阶级词典（简表）

- **核心五类**：`landlord` 地主、`richpea` 富农、`middle` 中农、`poor` 贫农、`tenant` 雇农。
- **其它原子类**：`comm` 公有土地、`others` 其他、`halflord` 半地主式富农、`highmid`/`lowmid` 上/下中农、`smallrent` 小土地出租者、`capitalist` 工商业资本家 等。
- **聚合类（源数据直接上报）**：`lordrich` 地富、`poortenant` 贫雇、`midpoortenant` 中农及贫雇。
- **协调层组名**：h5 用核心五类 + `other`；h3 用 `lordrich` / `middle` / `poortenant` + `other`。

## 6. 数据质量与已知局限（务必阅读）

### 6.1 溯源构成：绝大多数是原始记录
基于全部溯源单元（约 718,000 格）：

| 类别 | 占比 |
|---|---|
| 原始录入（`_src=0`） | **97.9%** |
| 算法填充（`_src=11/12/13/15`） | 2.0% |
| 覆写/重构（`_src=2`） | 0.1% |
| 待复核（`_src=9`） | 0.0%（153 格） |

也就是说，**近 98% 的核心数值直接来自县志原文**；填充部分全部可用来源码识别并剔除。

### 6.2 阶级细分覆盖率偏低（最大的使用门槛）
多数县只报告县级总量或聚合口径，能拆到完整阶级的县是少数：

| 协调层 | 土改前有覆盖 | 土改后有覆盖 |
|---|---|---|
| h5（五类） | 793 县（≈25%） | 639 县（≈21%） |
| h3（三组） | 1,179 县（≈38%） | 864 县（≈28%） |

> **含义**：需要完整阶级分解的分析，样本会显著小于 3,109。**优先使用 h3**（覆盖更广），并在论文中明确报告你实际使用的县数与筛选条件（如 `keep if h3_pre_coverage==1`）。

### 6.3 五个常见陷阱

1. **占比量纲**：用 `*_u`（0–1），别用原始 `*pct`（可能是 0–100）。
2. **merge 键**：用 `panel_uid`，**别用 `code`**——地级市与下辖县共用 code，且有个别 code 缺失。
3. **县级 vs 汇总行**：县级分析先 `keep if admin_level=="县"`，剔除 330 个市级聚合行。
4. **残差 `other`**：协调层的 `other = 县总 − Σ核心阶级`，是残差桶而非独立阶级；`other` 偏大通常意味着该县上报不全，别当作真实阶级解读。
5. **pre/post 不可混用阶级结构**：土改改变了阶级占有结构，两期的占比/人均不可互相替代或跨期借用（清洗仅允许县总耕地面积跨期互填，`_src=15`）。

### 6.4 待复核清单
自动检查标记的疑难县汇总在 `Reports/FinalClean/`：量级异常（`magnitude_pending_review`）、硬违反（`reconcile_pending`）、没收/分配一致性（`condis_consistency`）、综合裁决工作表（`pending_adjudication`）。若你的研究涉及被标记的县，请核对这些清单。

## 7. 快速上手

```stata
* Stata：载入宽表，筛出县级样本，做一个 h3 层的分析
use "FinalData/landreform_panel_wide.dta", clear
keep if admin_level == "县"                      // 剔除市级汇总行
keep if h3_pre_coverage == 1 & h3_post_coverage == 1   // 只留阶级可比的县
* 例：土改前后地富组人均土地对比
summarize h3_pre_lordrich_percap h3_post_lordrich_percap
```
